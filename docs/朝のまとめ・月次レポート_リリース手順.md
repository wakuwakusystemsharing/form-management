# 朝の「今日の予約まとめ」・月次レポート リリース手順

設計: `docs/朝のまとめ・月次レポート_実装設計.md`

## できること

- 毎朝、今日の予約（時刻・お名前・メニュー・担当・申し送り・新規 / VIP / 誕生月・注意あり）をスタッフのメール / LINE へ自動で送る
- 毎月 1 日、先月の予約数・売上・新規・リピート率・キャンセル率・前月比・人気メニュー・配信の成果を送る
- 管理画面のダッシュボード → 「月次レポートを見る」で、過去の月のレポートも見られる（こちらは設定なしで使えます）

既定はすべて OFF です。リリースしただけでは何も送られません。

## 手順

### 1. データベースの更新（staging / production それぞれ）

Supabase Dashboard → SQL Editor で `supabase/migrations/20261120000000_add_store_digest.sql` の内容を実行します。

- 作られるもの: `store_digest_settings`（設定・合言葉）/ `store_digest_staff`（LINE で受け取るスタッフ）/ `store_digest_logs`（送信の記録）
- 未適用のままでも既存の動きには影響しません（設定カードに「設定の取得に失敗しました」と出るだけ。月次レポートの画面は見られます）

### 2. アプリのデプロイ

通常どおり PR をマージします（環境変数の追加・Edge Function の再デプロイは不要）。
メールで送る場合は、Web 予約のメール通知と同じ `RESEND_API_KEY` / `EMAIL_FROM_ADDRESS` が設定されている必要があります。

### 3. 毎時の送信（cron）の登録 — **本番のみ**

本番の Supabase Dashboard → SQL Editor で実行します（`<SERVICE_ROLE_KEY>` は本番プロジェクトの Service Role Key）。

```sql
select cron.unschedule('run_store_digest');  -- 既に登録済みなら削除（無ければエラーになるが無視してよい）

select cron.schedule(
  'run_store_digest',
  '0 * * * *',
  $$
    select net.http_post(
      url := 'https://nas-rsv.com/api/cron/store-digest',
      headers := jsonb_build_object(
        'Content-Type', 'application/json',
        'Authorization', 'Bearer <SERVICE_ROLE_KEY>'
      ),
      timeout_milliseconds := 30000
    );
  $$
);
```

- cron を登録するまで、自動では送られません（テスト送信と月次レポートの画面は使えます）
- **staging の Vercel はログイン保護のため cron から呼べません**。staging は設定カードの「テスト送信」で確認します

### 4. 店舗ごとの設定

1. 店舗管理者ページ → 設定（またはテナント側 店舗ページ → 設定）→ 「今日の予約まとめ・月次レポート」
2. 送る内容と時刻を選ぶ
3. 送り先を選ぶ
   - メール: アドレスを 1 行に 1 件（5 件まで）
   - LINE: 受け取るスタッフが、お店の公式 LINE を友だち追加して「スタッフ登録 合言葉（画面に表示の 4 桁）」と送る
4. 「保存」→ 「テスト送信」で届くことを確認

## 動作確認（staging）

1. 設定カードでメールアドレスを入れて「メールで受け取る」を ON → 保存
2. 「今日の予約まとめをテスト送信」→ メールが届く（今日の予約が無ければ「本日の予約はありません」）
3. 「LINE で受け取る」を ON → 保存 → 自分の LINE から公式 LINE に「スタッフ登録 合言葉」を送る → 「スタッフとして登録しました」と返る → 一覧に名前が出る
4. もう一度テスト送信 → LINE にカードが届く。「管理画面で見る」で予約管理が開く
5. アレルギーを登録した顧客の予約がある日: 「注意あり」と出て、内容は載っていないこと
6. 「月次レポートをテスト送信」→ 先月の数字が届く。「くわしく見る」で月次レポートの画面が開く
7. ダッシュボード → 「月次レポートを見る」→ 月を切り替えられること。数字が予約管理 → 分析の同じ期間と合うこと
8. 違う合言葉を送る → 「合言葉が違います」。5 回間違える → 合言葉が無効になり「合言葉を出し直す」で戻ること
9. 「スタッフ登録解除」と送る → 一覧から消えること

## 店舗への案内（例）

> 毎朝 8 時ごろ、その日のご予約の一覧が LINE（またはメール）に届くようになります。
> 受け取りたいスタッフの方は、お店の公式 LINE に「スタッフ登録 ◯◯◯◯」（合言葉）と送ってください。
> 毎月 1 日には、前の月の予約数や売上のまとめも届きます。
