# LINE メッセージの分岐（ボタンを押したら次のメッセージを返す）実装設計

## 何ができるか

公式 LINE に送ったメッセージのボタンをお客様が押すと、押したボタンに応じて次のメッセージが届く。
質問 → 選択肢 → 次の質問 … と続けて、アンケートや診断のように使える。

- 選んだ内容に応じて、お客様の顧客情報にタグを付けられる（配信の絞り込みに使える）
- 何人がどれを選んだかを一覧で見られる
- 顧客詳細の「LINE」タブで、そのお客様が選んだ内容を見られる

## 作り方は 2 つ

### かんたんモード: テンプレート「分岐アンケート（かんたん）」

「新規作成」→ テンプレートで「分岐アンケート（かんたん）」を選び、上から順に入力する。

1. 質問文と、選択肢（ボタンの文言）を入れる
2. 選択肢ごとに「選んだら」を選ぶ
   - 次の質問を出す
   - 結果を出す（見出し・説明・画像・ボタン 1 つ。ボタンは予約フォームの URL など）
   - 保存済みの LINE メッセージを送る（クーポン・店舗紹介など、すでに作ってあるもの）
   - 何も返さない（記録とタグ付けだけ）
3. 必要なら「タグ」で、その選択肢を選んだお客様に付けるタグを設定する

各質問・結果の「プレビューで見る」を押すと、そのカードが右のプレビューに出る。

| 上限 | 値 |
| --- | --- |
| 1 つの質問の選択肢 | 6 個 |
| 質問を重ねる深さ | 5 段 |
| 質問 + 結果の合計 | 40 個 |

### くわしくモード: ボタンの動きを「次のメッセージを送る」にする

どのテンプレートでも、ボタンの動きを次の 2 つから選べる。

- 押したら URL を開く（予約フォーム・電話など。これまでどおり）
- 押したら次のメッセージを送る（分岐）→ 送る LINE メッセージを選ぶ。タグも設定できる

テンプレートのボタン欄と、プレビューの下の設定欄（ボタンを選んだとき）のどちらでも設定できる。
メッセージを 1 つずつ作ってつなぐので、見た目を自由に作り込みたいときに向く。

## お客様のトークに選んだ内容を表示するか

編集画面 →「その他」→「分岐ボタンを押したとき、選んだ内容をお客様のトークに表示する」（メッセージごと。既定は ON）。

- ON: ボタンの文言（例:「カット」）がお客様の発言として表示される
- OFF: 何も表示されず、次のメッセージだけ届く

## 回答の見方

- 一覧で、分岐のあるメッセージ（「分岐あり」の印）の「プレビュー編集」を開くと、下に「回答の集計」（質問ごとに、選んだ人数と押された回数）
- 顧客管理 → 顧客詳細 →「LINE」タブに「LINE メッセージで選んだ内容」

## しくみ

| 場面 | 処理 |
| --- | --- |
| 作るとき | ボタンのリンク先に `next:{メッセージID}?tags=…`（くわしくモード）/ `choice:{選択肢のキー}`（かんたんモード）と書く |
| 保存するとき | サーバーがこれらを LINE の postback ボタン（`data = lf:{メッセージID}:{キー}`）に置き換え、対応表 `branches` を作る。分岐アンケートの 2 問目以降・結果は送信用メッセージを作って `branch_payloads` に保存 |
| 押されたとき | Webhook が postback を受け、`line_flex_answers` に記録 → タグ付け → 次のメッセージを返信 |

- 純粋ロジック: `src/lib/line-flex-branch.ts`（リンク先の書き方・postback・集計）/ `src/lib/line-flex-scenario.ts`（分岐アンケートの木）
- サーバー: `src/lib/line-flex-service.ts`（`prepareLineFlexMessage` / `handleLineFlexPostback`）/ `src/lib/line-flex-answers.ts`
- 画面: `ScenarioEditor.tsx` / `FlexLinkField.tsx` / `LineFlexAnswerSummary.tsx` / `CustomerLineAnswers.tsx`
- API: `GET /api/stores/{storeId}/line-messages/{id}/answers`（集計）/ `GET /api/stores/{storeId}/line-messages/answers?line_user_id=`（お客様ごと）

## データ

マイグレーション `20261116000000_add_line_flex_branching.sql`

- `line_flex_messages`: template に `scenario` を追加、`branches` / `branch_payloads` / `show_choice_text` 列
- `line_flex_answers`: ボタンが押された記録（1 回押す = 1 行。店舗・メッセージ・ボタン・質問文・文言・LINE ユーザー ID・日時）

## リリース手順

1. Supabase（staging → 本番の順）の Dashboard → SQL Editor で `20261116000000_add_line_flex_branching.sql` を実行
2. PR をマージ
3. Edge Function の再デプロイ・cron の変更は不要

マイグレーションより先にマージしてしまっても、分岐を使っていない LINE メッセージの保存は今までどおり動く（分岐のあるメッセージだけ「データベース更新がまだ」と出て保存できない）。

## 注意

- 次に送る LINE メッセージを削除・無効にすると、そのボタンを押しても何も返らない（保存時には存在を確認する）
- タグは、押したお客様が顧客管理に登録されているときだけ付く（友だち登録だけの人も自動で登録されるので、通常は付く）
- 予約確認・リマインダー・フォロー・配信に添えたメッセージの分岐ボタンも同じように動く
