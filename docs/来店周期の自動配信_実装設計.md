# 来店周期の自動配信（いつもの来店間隔に合わせてお誘い）実装設計

自動配信のきっかけ `visit_cycle`（テンプレートの 6 つ目「いつもの来店間隔に合わせてお誘い」）。
固定の「◯ 日後」ではなく、**お客様ごとのいつもの来店間隔**がたった頃に「そろそろいかがですか」を送る。

## 1. 仕様

| 項目 | 内容 |
|---|---|
| いつもの来店間隔 | （最終来店日 − 初回来店日）÷（来店回数 − 1）を四捨五入。連続する来店の間隔の平均と同じ値（`customers.average_visit_interval_days` と同じ考え方） |
| 対象 | 来店 2 回以上のお客様。間隔が 7 日より短い人は 7 日として扱う。1 年を超える人は対象外（「休眠のお客様へ」の役割） |
| 来店 1 回の人 | ルールの「来店が 1 回のお客様にも送る」を ON にすると、入力した目安の日数（7〜365。初期値 45）を間隔として使う。OFF なら送らない |
| 送る日 | 最終来店日 + いつもの来店間隔 + ずらす日数（少し前 = マイナス / ちょうど = 0 / 少し後 = プラス。最大 30 日）。前にずらしても最短で来店の翌日 |
| 送らない人 | **これからの予約がある人**（絞り込みの設定に関係なく常に除く）。LINE 未連携・配信停止・ブロック中は他のきっかけと同じ |
| 同じ人への回数 | 同じ最終来店日に対して 1 回だけ（marker = `cycle:{最終来店日}`）。次に来店すると、また間隔がたった頃に送る。「同じお客様に次に送るまで ◯ 日あける」も効く |
| ON にした日の扱い | 送る日を過ぎてから 14 日以内（`AUTOMATION_WINDOW_DAYS`）の人だけ。長く来店の無い人へ一斉に送らない |
| 実行 | ほかの日数系のきっかけと同じ。1 日 1 回、店舗の実行時刻（`stores.broadcast_automation_time`）に判定 |

### 注意（来店記録の作られ方）

来店記録（`customer_visits`）は予約が成立した時点で予約日の日付で作られる。そのため、これからの予約がある人は最終来店日が先の日付になり、
その時点で判定から外れる（さらに予約データでも確認して除く）。その予約日を過ぎると、そこから間隔を数え直す。

## 2. 構成

| 種類 | ファイル |
|---|---|
| 型 | `src/types/broadcast.ts`（`AutomationTrigger` の `{ type: 'visit_cycle', offset_days, first_visit_days }`） |
| 純粋ロジック | `src/lib/broadcast-visit-cycle.ts`（`normalizeVisitCycleTrigger` / `customerVisitCycleDays` / `visitCycleDueDays` / `describeVisitCycleTrigger` / `VISIT_CYCLE_DEFAULT_TRIGGER`） |
| 判定への組み込み | `src/lib/broadcast-automation.ts`（`AUTOMATION_TEMPLATES` / `normalizeAutomationTrigger` / `evaluateAutomationTrigger` / `pickAutomationTargets` = これからの予約がある人を除く） |
| サーバー | `src/lib/broadcast-automation-service.ts`（`selectTargets` が `visit_cycle` のとき予約を必ず読み込む。見積り・実行は既存の流れのまま） |
| 画面 | `src/components/broadcast/BroadcastAutomationPanel.tsx`（`TriggerFields` の `visit_cycle`） |
| テスト | `broadcast-visit-cycle.test.ts` / `broadcast-visit-cycle-service.local.test.ts` |

DB・API・Edge Function・cron の変更なし（`broadcast_automations.trigger` は JSONB）。

## 3. リリース

PR をマージするだけ。自動配信の cron（`run_broadcast_automations`）が登録済みの環境で動く。
staging は配信タブ → 自動配信 → 「今日の判定を今すぐ実行」で確認する。
